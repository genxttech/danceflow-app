## Runbook: signed-in Student QA on a disposable stack (QA-only; nothing here is committed to shipping config)

Prerequisites: Docker running, nothing else using Gradle, the emulator or an iso-qa stack (check `docker ps`, `Get-Process java`, `adb devices`). One build or stack at a time on this PC.

1. Stack (about 5 minutes): `node scripts/qa/iso-qa.mjs up main --name stu --auth` from a checkout of `main`; note `ISO_QA_ANON_KEY` and `ISO_QA_SERVICE_ROLE_KEY` from its output (Kong on `http://127.0.0.1:56600`).
2. Push-token function: `docker exec -i df-isoqa-stu-db psql -U postgres -d postgres -v ON_ERROR_STOP=1 < src/lib/supabase/migrations/20270213080000_mobile_push_token_claim.sql`.
3. Dancer: `POST http://127.0.0.1:56600/auth/v1/admin/users` with the service key, body `{"email":"dana.dancer@example.test","email_confirm":true}`; keep the returned `id`.
4. Seed (studio, client, linked account, two pending payments): `docker exec -i df-isoqa-stu-db psql -U postgres -d postgres -v uid="'<id>'" < seed.sql` where `seed.sql` inserts into `studios (id,name,slug)`, `clients (id,studio_id,first_name,last_name,email)`, `client_account_links (studio_id,client_id,user_id,status='linked',relationship_type='self',initiated_by='dancer',linked_at,can_*=true,is_primary=true)` and `payments (id,studio_id,client_id,amount,payment_method='card',status='pending',payment_type,notes,currency='usd')`. Wrap the inserts in `set local session_replication_role = replica;` because the baseline's `reward_on_paid_payment` trigger breaks a plain insert (enum cast of `''`). The status of an account link must be one of `unclaimed, invited, claim_pending, linked, disconnected, former_client, rejected, conflict`.
5. Web API mock (about 30 lines of node, `0.0.0.0:8791`): serve `GET /api/student/studio-links` as `{hasPortalAccess:true, linkedStudios:[STUDIO], primaryStudio:STUDIO, lumiEnabled:false}` (STUDIO has `clientId`, `studioId`, `studioSlug`, `studioName`, `studioPublicName:null`, names/email, `isIndependentInstructor:false`, `lumiEnabled:false`, `status:"linked"`, `relationshipType:"self"`), `GET /api/student/profile` as `{profile:{...}}`, and any HTML for `/api/stripe/client-checkout`; everything else 404 JSON. Wallet, schedule and profile reads go straight to Supabase, so the seed rows show up without the real web app.
6. Build in a short real path (not a `subst` drive; for example `C:\dq`, a `git worktree` of `main`): write `mobile/student/.env` with `EXPO_PUBLIC_SUPABASE_URL=http://10.0.2.2:56600`, `EXPO_PUBLIC_SUPABASE_ANON_KEY=<anon>`, `EXPO_PUBLIC_DANCEFLOW_WEB_URL=http://10.0.2.2:8791`; add `android:usesCleartextTraffic="true"` to `<application>` in `android/app/src/main/AndroidManifest.xml` (local edit, revert it); clear `app/build/{generated/assets,intermediates/{assets,merged_assets,compressed_assets,incremental},outputs/apk/release}`; point `TEMP`/`TMP` at an empty folder so Metro does not reuse a stale cache (a stale cache keeps an old inlined URL); create a throwaway keystore with `keytool -genkeypair ... -validity 30` outside the repo and export `DANCEFLOW_UPLOAD_STORE_FILE`, `DANCEFLOW_UPLOAD_STORE_PASSWORD`, `DANCEFLOW_UPLOAD_KEY_ALIAS`, `DANCEFLOW_UPLOAD_KEY_PASSWORD`; then `./gradlew.bat :app:assembleRelease --no-daemon -PreactNativeArchitectures=x86_64 -PallowPlaceholderGoogleServices=true` with `NODE_ENV=production` (about 9 to 11 minutes). Release builds refuse debug signing and a placeholder `google-services.json` (#513); the second flag is the documented local-verification switch.
7. Device: boot `emulator -avd df-api35 -no-snapshot -no-boot-anim -gpu swiftshader_indirect -memory 2048 -no-audio`; `adb install -r app-release.apk` (uninstall first if the signature differs); sign in with a magic link made through `POST /auth/v1/admin/generate_link` (`{"type":"magiclink","email":...}`) and opened as `danceflow://auth/callback?token_hash=<hashed_token>&type=magiclink` (GoTrue's own mail send to Mailpit times out under load); screens by deep link: `danceflow://settings`, `danceflow://wallet/payment-requests`. `MSYS_NO_PATHCONV=1` in Git Bash.
8. Tear down: restore `font_scale`, `uimode night no`, animation scales, `hide_error_dialogs 0`; `adb uninstall`; stop the mock; `node scripts/qa/iso-qa.mjs down --name stu --force`; revert `.env` and the manifest edit; delete the throwaway keystore.
