## 4. Decisions and holds (not changed by this slice)

- **D-S0-1 (owner/ops)**: wave-autopost is not scheduled in `vercel.json` (W1). Whether it is scheduled externally or never ran is unknown from the repo. This slice does not edit `vercel.json`; the owner decides whether to add a cron entry (and on what cadence).
- **D-S0-2 (engineering, low risk)**: when encrypt switches from `v1` to `v2` output; proposed only after S0-g1 is deployed everywhere decrypt-capable (avoids older instances failing to read new ciphertext).
- PROD: no hosted SQL, env, flag or cron change. DEV apply only after independent review.
- Out of scope: G7 data minimisation, G9/W6 refresh lock (A1/A3), G11 plan gating, W7 Wave terms check, W4, W8 RPC sweep, gusto.

## 5. Wave revoke caveat

Wave's public docs must be checked for a token-revocation endpoint before S0-b implements one; if none is documented the PR documents the limitation and stops short of inventing an endpoint.
