## Overview

Approving a request carries it out: it books, reschedules, or cancels the appointment. Declining a request keeps the calendar unchanged and records the staff decision.

## Approving a request

Go to **Self-service Requests** (the **Schedule Requests** page) and find the request on the **Pending** tab.

Before approval, review:

- Client name
- Requested date and time
- Instructor
- Room
- Lesson type
- Notes from the client

For bookings and reschedules, DanceFlow rechecks eligibility and conflicts. If both pass, the schedule is updated and the request moves to the **Executed** tab. Otherwise an error is shown.

## Declining a request

Decline a request when the requested time or setup does not work.

You can add an optional decline note. The client sees it in their portal, so write it for them, for example with a suggested alternate time.

## What clients see

Clients see the request status and any decline note under **Recent requests** in their portal. Do not rely on an email; contact the client directly.

## Best practice

Use approval for times you are confident can be honored. Use decline when the client needs a different time, different instructor, or additional follow-up before scheduling.
